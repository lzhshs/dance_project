# Presentation Video Candidates

These videos are selected for the 5-minute oral presentation. They are renamed
by story role so they are easier to insert into slides.

## Recommended core videos

1. `01_waack_pinned_showcase_best_visual.mp4`
   - Best opening demo.
   - Shows the most expressive robot dance.
   - Use with the label: pinned-root showcase / visual demo.

2. `02_waack_freeroot_stable_physics.mp4`
   - Best physics contrast to video 01.
   - Shows the same style as a stable free-root rollout.
   - Use with the label: free-root stable / physical rollout.

3. `03_pop_pinned_showcase_best_visual.mp4`
   - Good shorter/local example.
   - More connected to the local generated pop motion.
   - Use if Waack feels too extreme.

4. `04_pop_freeroot_stable_physics.mp4`
   - Stable counterpart to video 03.
   - Use to show the two-version output on the pop example.

## Optional supporting videos

5. `05_pop_expressive_freeroot_fall_example_no_audio.mp4`
   - Optional failure example.
   - Shows why expressive free-root motion is risky.
   - No audio; use only if you want a short "before" clip.

6. `06_waack_original_showcase_pinned_reference.mp4`
   - Optional reference showcase.
   - Similar to video 01, kept as a backup.

## Suggested presentation use

- Opening slide: use video 01 for visual impact.
- Method/results slide: compare video 01 vs video 02.
- Backup demo: use video 03 vs video 04 if the audience asks about the local
  pop generated motion.
- Failure motivation: optionally show video 05 for one or two seconds to explain
  why free-root evaluation matters.
